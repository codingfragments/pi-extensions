13 · Layout principles

Fluid workspace, capped prose, one comfortable density, one responsive policy, a stable layer order.

Capped prose in a fluid area

Tables, footage and the map use all the width they get.

Narration and descriptive text stay within about 68 characters per line, however wide the window is, so long text remains easy to read and to edit.

Responsive policy

Components respond to the width of their own container, not the window. The list and inspector collapse below 52 rem; two-column details and secondary table columns fold below 60 rem; the map hides its side panel below 60 rem; the header drops stepper labels below 64 rem. Those four container thresholds are the whole policy.

Layer order, low to high
  1. Page and sticky header, status strip (20)
  2. Activity drawer (40)
  3. Map overlay (50)
  4. Dialog (60)
  5. Toast (70)

Escape closes only the top layer; closing returns focus to what opened it.

Spacing rhythm

Gaps between related controls: 8. Between groups in a form or card: 12–16. Between sections of a page: 16–24. Page padding: 16.
